description: 恢复上次工作进度。在任何电脑上说"继续"即可继续上次的工作。
---

## 目标

读取项目进度文件并汇报当前状态，让用户无缝继续工作。

## 流程

1. 读取 `CLAUDE.md` 了解项目总览
2. 读取 `.claude/memory/progress.md` 获取当前进度
3. 如果有未提交的变更，提醒用户
4. 输出：**当前阶段**、**已完成**、**下一步**、**最近变更**

## 汇报模板

```
📍 当前阶段：{phase}
✅ 已完成：{done list}
👉 下一步：{next task}
📝 最近变更：{recent changes}
```

如果用户没有特殊指示，就按下一步继续工作。
